🌍 Qu'est-ce que cette application ?

App A. TOP — Analyse du Climat est une application en ligne qui vous fournit les moyennes climatiques mensuelles de n'importe quel lieu dans le monde, à partir de données satellites NASA / Open-Meteo (réanalyses ERA5).

Elle vous permet d'obtenir, en quelques secondes :

  • 🌡️ Les températures moyennes (minimales, maximales, moyennes)
  • 🌧️ Les précipitations mensuelles
  • 💧 L'humidité relative
  • 💨 La vitesse du vent
  • ☀️ L'ensoleillement

Vous pouvez analyser un seul lieu ou comparer plusieurs lieux (jusqu'à 5) côte à côte, puis exporter vos résultats en Word, Excel ou PDF.

📍 Comment analyser un lieu

  1. Sur la page d'accueil, choisissez le mode « Un lieu ».
  2. Indiquez le lieu de l'une des trois manières possibles :
    • Nom du lieu : tapez par exemple « Dakar, Sénégal »
    • Coordonnées GPS : saisissez la latitude et la longitude
    • Sur la carte : cliquez directement sur le point souhaité
  3. Choisissez le nombre d'années à analyser (de 1 à 30 ans). Plus la période est longue, plus l'analyse est représentative, mais le calcul peut prendre quelques secondes de plus.
  4. Cochez les variables que vous souhaitez analyser.
  5. Cliquez sur « Analyser ».
  6. Sur la page de résultats, vous pourrez consulter les tableaux et graphiques mensuels, et exporter en Word, Excel ou PDF.

🔀 Comment comparer plusieurs lieux

  1. Sur la page d'accueil, cliquez sur le bouton « 🔀 Comparer plusieurs lieux ».
  2. Saisissez les noms des lieux à comparer (de 2 à 5 lieux). Cliquez sur « + Ajouter un lieu » pour ajouter une ligne.
  3. Choisissez le nombre d'années communes à analyser pour tous les lieux.
  4. Cochez les variables à comparer. Les mêmes variables seront analysées pour tous les lieux.
  5. Cliquez sur « Analyser ».
  6. Sur la page de résultats, vous verrez un tableau côte à côte pour chaque variable, ainsi qu'un résumé par lieu.

🛠️ En cas de difficulté

⏳ Le premier appel peut prendre 30 à 60 secondes — c'est normal. L'application est hébergée sur un serveur gratuit qui « se réveille » lors de la première requête. Les requêtes suivantes sont beaucoup plus rapides.

Si un lieu n'est pas reconnu :

  • Essayez d'ajouter le pays au nom (ex : « Saint-Louis, Sénégal »)
  • Ou utilisez le mode Coordonnées GPS ou Sur la carte

Si l'analyse échoue ou prend trop de temps :

  • Réduisez le nombre d'années demandées (essayez 5 ou 10 ans)
  • Réduisez le nombre de variables cochées
  • Vérifiez votre connexion Internet
  • Rafraîchissez la page (F5) et réessayez

Si l'export Word/Excel/PDF ne fonctionne pas :

  • Assurez-vous d'avoir d'abord lancé une analyse
  • Si la session a expiré, relancez votre analyse
